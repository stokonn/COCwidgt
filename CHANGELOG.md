# Changelog

Notable user-facing changes are documented here. Detailed implementation notes and verification boundaries are linked from each release entry.

## [0.6.0] — prerelease

- Added multiple saved accounts identified by Player Tag.
- Added account rename, active-account selection and local removal.
- Isolated village exports, profile details and cached names per account.
- Added first-launch migration from the original single-account storage.
- Added per-widget account assignment.
- Added Town Hall 19 catalogue metadata and selected artwork updates.
- Improved adaptive widget content planning.
- Accepted an optional UTF-8 byte order mark in imported village JSON.
- Preserved unsupported and over-cap catalogue rows with diagnostics.

See [0.6.0 release notes](docs/releases/0.6.0.md) and [verification record](docs/verification/0.6.0.md).
