# COCwidgt 0.6.0

<sup>Published prerelease · Android version code 7</sup>

**COCwidgt 0.6.0** introduces multiple saved accounts, per-widget account selection and Town Hall 19 catalogue/artwork updates while retaining the manual village-export workflow.

- [GitHub release](https://github.com/stokonn/COCwidgt/releases/tag/v0.6.0)
- [Download APK](https://github.com/stokonn/COCwidgt/releases/download/v0.6.0/cocw0.6.0.apk)
- [Release notes used by the workflow](../../.github/release-notes-v0.6.0.md)

## Highlights

### Multiple accounts

- Add and manage multiple accounts by Player Tag.
- Rename local account labels, switch the active account and remove saved accounts.
- Keep village exports, profile details and cached names isolated per account.
- Migrate an existing single-account installation on first launch.
- Assign a different saved account to each home-screen widget instance.

### Town Hall 19 catalogue

- Add verified TH19 catalogue data based on the cited ClashKingAssets revision.
- Include new buildings and supported level-cap updates across relevant game categories.
- Include Town Hall 19 and its available variants, new structure artwork, Heroic Spell, Squad troop portraits and Guardian portraits.
- Preserve unknown IDs and report unsupported IDs, catalogue level overruns and timed rows for non-upgradeable entities.

### Widget and import improvements

- Plan widget rows using launcher-reported dimensions and the active upgrade count.
- Hide a redundant compact status line on very small widgets to preserve space for an upgrade row.
- Accept an optional UTF-8 byte order mark in imported JSON.
- Keep imported rows when the catalogue cannot confidently map them.

## Compatibility

- Minimum Android version: Android 10 (API 29).
- Application ID: `dev.stokonn.cocwidgt`.
- Version name: `0.6.0`.
- Version code: `7`.

## Important limitations

- Village data is still obtained through manual Data Export and import. The app does not have a live connection to the game.
- Player profile lookup remains optional and uses the Developer API key; it does not provide village upgrade state.
- Guardian Shrine is catalogued as non-upgradeable and has no standalone building artwork in the cited upstream revision.
- The export representation of the selected Town Hall 19 visual variant has not yet been validated against a physical TH19 export sample.
- Widget refresh timing and final layout depend on Android and the installed launcher.
