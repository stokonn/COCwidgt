# Security policy

## Supported version

The current development line is **0.6.0 prerelease**. Security fixes should be assessed against the current `main` branch and the latest published release.

## Reporting a vulnerability

Please do not publish API keys, signing material, private account data, or exploit details in a public issue.

For a suspected vulnerability, use GitHub's private vulnerability reporting feature for this repository if it is enabled. If private reporting is unavailable, contact the repository maintainer through the contact options on the GitHub profile and request a private channel before sharing technical details.

Include:

- A concise description of the affected component.
- The impact and conditions required to reproduce the issue.
- The affected app version, Android version and device context.
- A safe reproduction or proof-of-concept that does not expose real credentials or personal data.

## Sensitive data

- Never include Developer API keys, keystore files, signing passwords or access tokens in issues, pull requests, commits or logs.
- Do not attach unredacted village exports if they contain personal or account information.
- COCwidgt's village import is designed to remain local. Report any unexpected network transfer of village data as a high-priority privacy/security concern.

## Scope

This policy covers the COCwidgt source repository, its Android application and its project-maintained GitHub workflows. Third-party services and the Clash of Clans game are outside the project's control.
